# CivicDoc Scrubber

Chrome extension that detects and masks common sensitive patterns on webpages to support privacy-conscious documentation and review workflows.

## Features
- Redacts phone numbers, emails, and SSN-like patterns
- Runs entirely client-side
- Toggleable via popup UI
- Designed for public-sector and regulatory workflows

## Example Use Case
When reviewing public regulatory or municipal websites, it is easy to accidentally copy contact details into internal drafts. CivicDoc Scrubber masks those patterns directly in the browser to reduce accidental disclosure.

## Demo
Tested on public-sector websites such as CalEPA contact pages.
